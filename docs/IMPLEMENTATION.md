# 新上传GDD的手机可玩切片

依据：2026-11-06用户上传的《冷宫开席_GDD_v0.1.md》，文内版本0.4。原稿逐字保留在`docs/GDD.md`，不以旧网页的逻辑回写原稿。

本轮可玩范围：第一碗野菜汤、太监态度反转、首批种子请求、清地/理床、播种与跨日照料/留种、杂草堆肥、三项主要修缮、一场有两条物资路线的查办。宫宴、皇帝饭友和更多事件属于下一阶段，界面不会声称已实现。

## 原稿规定与实现

| 原稿要求 | 本版实现 |
|---|---|
| 首菜野菜汤；太监参与挖菜，喝汤后才改观 | 首次共同采菜后仍敷衍；上桌后演出闻香、尝汤、再一口、主动问缺什么 |
| 秸秆作真实燃料，固定取水点 | 汤检查野菜/清水来源/秸秆；不能静默烧修缮木料 |
| 经营日劳作与自食 | 常驻今日/劳作/自食；玩家确认结束今日，作物按经营日推进 |
| 物品多用途 | 秸秆可烧火或铺地；草清理后独立加工成肥；使用一次只扣一次 |
| 背包与屋内合计使用、位置保留、无容量 | 分类显示背包/屋内/持有/预留/可用；一键存入屋内不扣劳作 |
| 预留、缺料定位 | 菜谱方案可预留已有物资；不足只列缺口；可取消，更换释放旧预留 |
| 人物请求与交付节点 | 首包种子清地理床后可领取；后续请求显示帮忙次数、费用和交接状态 |
| 种植按经营日而非秒数 | 播种、批量照料、跨日成熟；离线不枯死；收菜和留种互斥 |
| 两种方案都能招待放行 | 首次查办用菜饼或补面粉做汤面，均满足公开标签，无隐藏失败概率 |
| 手机操作位吸附 | 进入操作位半径后缓动到锚点并锁定；显示“已就位”；再次拖动/按键/点地面退出，有短暂防回吸 |

## 原稿留待配置的数值

以下为本切片的原型参数，不声称原稿已全部写死：每天劳作4；首次挖野菜耗1劳作得4；拾手边秸秆每日得3且不额外耗劳作；首次取水和顺手理床不耗劳作；野菜汤用叶菜2/秸秆1/劳作1产2份；首包种子不耗劳作、不占常规帮忙。清地耗1得杂草2，播种耗种子1/劳作1。如此首日总劳作正好4，完成自食、待客、清地、播种。

作物播种视作当日已照料，经过2次已照料跨日成熟，收获耗1得菜6；留种放弃当轮收获，2次跨日后耗1取种2。肥料用草2/劳作1制作；施肥本次额外产2；秸秆铺地消耗1，替代一次未完成的照料，不能兼作当锅燃料。

后续菜饼叶菜2/面粉1/秸秆1/劳作1→2份；清汤面叶菜1/面粉2/秸秆1/劳作1→2份。它们承接原稿第十四章的两路线消耗，并补上正文要求检查的真实燃料。

屋顶材料1/劳作2，灶台材料2/劳作2，第二块地材料1/劳作2；床铺整理是首局小改善，不代替三项主要修缮。材料来自既有旧木整理或明确食物交换。常规帮忙每日一次、请求耗劳作1；预计交付不计入库存。

首次查办在完成首轮种植并具备两条路线时开放；可单独从设置进入查办测试档。测试起始叶菜4/面粉1/种子1/材料1/燃料2/劳作4，房屋未修、旧灶可用，向太监补面粉耗1劳作。该测试档与正常生活存档独立，不将测试物资转进生活档。
